# Autonomous-Underwater-Surveillance-Drone-AUSD-
The AUSD is an advanced AUV for coastal defense, integrating sonar with onboard AI (YOLO-v8/CNNs) to achieve 95%+ accuracy in anomaly detection. Designed for real-time surveillance of maritime infrastructure, it features a seabed-mounted magnetic induction station for autonomous recharging, ensuring continuous, long-term underwater operation.
